Perguntas

O que todo mundo pergunta.

Precisa de internet para usar?

Não para montar o orçamento. O app guarda tudo no celular. Só precisa de sinal na hora de mandar pelo WhatsApp.

Funciona no iPhone?

A primeira versão sai para Android, na Google Play. A versão para iPhone vem logo depois.

O cliente precisa baixar alguma coisa?

Não. Ele recebe o PDF no WhatsApp e abre no celular como qualquer arquivo.

Meus preços ficam visíveis para outras pessoas?

Não. Sua lista de serviços e seus orçamentos ficam no seu celular. Só o cliente vê o orçamento que você mandar para ele.
